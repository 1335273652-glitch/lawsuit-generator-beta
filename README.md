# 人身损害诉状生成器 0.11β

公开测试版，包含律师题库、2026 年分省基数、七类赔偿计算、保险责任分配、工伤待遇分列，结构化的原告与多名被告信息，按赔偿项目动态加载的九步精简问卷，以及保存在本机浏览器中的历史诉状记录。

简版 `admin.html` 管理后台保留数据概览、用户记录、问卷管理、文书模板和文书记录五项。网页演示通过 `?role=admin` 展示管理员视图，数据只保存在本机；正式小程序由云函数使用微信 `OPENID` 和云端角色共同鉴权。

`miniapp.html` 是微信小程序用户端的浏览器原型。首页只提供“人身损害类诉状”一个产品入口，进入问卷后再根据受伤场景动态分流，保留云端草稿、历史文书以及“首页、文书、我的”三栏结构。“我的”页面展示微信账号、头像、同步状态、设置与隐私；管理员入口只对管理员显示，并进入简版后台。

`index.html` 内置题库与参数备用数据，在文件夹内直接打开时也能完成完整问卷；线上运行时仍优先读取独立数据文件。

计算逻辑通过 `tests/case-engine.test.js` 中的规则验收用例验证。标注待核的省级工资和未配置的“两金”月数不会自动套用全国值。
