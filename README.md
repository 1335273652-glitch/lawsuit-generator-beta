# 人身损害诉状生成器 0.8β

公开测试版，包含律师题库、2026 年分省基数、七类赔偿计算、保险责任分配、工伤待遇分列，结构化的原告与多名被告信息，按赔偿项目动态加载的九步精简问卷，以及保存在本机浏览器中的历史诉状记录。

0.8β 新增匿名流程埋点及 `admin.html` 测试管理后台，可查看核心转化漏斗、案件类型分布、步骤完成/校验失败情况及事件明细，并支持 CSV、JSON 导出和多个测试文件合并。当前 GitHub Pages 版本只保存本机数据；正式运营前需接入服务端数据库和管理员鉴权，详见 `ADMIN_ANALYTICS.md`。

`miniapp.html` 是微信小程序用户端的浏览器原型，包含四类案件入口、云端草稿/历史文书入口，以及“首页、文书、我的”三栏结构。“我的”页面展示微信账号、头像、同步状态、设置与隐私；管理员入口只对云端角色为 `admin` 的账号显示。

`index.html` 内置题库与参数备用数据，在文件夹内直接打开时也能完成完整问卷；线上运行时仍优先读取独立数据文件。

计算逻辑通过 `tests/case-engine.test.js` 中的规则验收用例验证。标注待核的省级工资和未配置的“两金”月数不会自动套用全国值。
